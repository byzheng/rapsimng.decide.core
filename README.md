# rapsimng.decide.core

`rapsimng.decide.core` provides a low-level interface for analysing APSIM Next Generation simulation outputs through structured decision workflows.


---

## Installation

Currently on [Github](https://github.com/byzheng/rapsimng.decide.core) only. Install with:

```r
remotes::install_github('byzheng/rapsimng.decide.core')
```
